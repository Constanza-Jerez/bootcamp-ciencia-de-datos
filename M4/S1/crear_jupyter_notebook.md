1. Abrir VS code
2. Instalar extensión jupyter notebook
3. Escribir en la busqueda del vs code `> jupyter`
    otra opción:
    - ctrl + shift + p
    - abre la busqueda e ingresan `>jupyter`
4. Seleccionar la opción crear jupyter notebook
5. Ya se tiene un archivo para trabajar con librerias de ciencia de datos
